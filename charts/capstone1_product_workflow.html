Day in the life — Capture → Audit

Differentiated lead desk for individual agents: transparent bands, lasting lead memory, assistive property match, and prepaid LLM quotas. Drafts only — the agent always sends. Compete on inspectability and spend control, not on auto-WhatsApp like portal CRMs.

Speed

HOT leads surface first with a plain-language why — call before the queue dies.

Memory

Inspectable

Rules-first HOT WARM COLD — override anytime; no black box.

Spend control

Rules scoring is free; LLM drafts meter against prepaid credits with soft/hard stops.

Optional operational signals (never demographic proxies)

  • Financing readiness (pre-approved / cash / unknown)
  • Typology fit (T1/T2/…) and max price vs budget consistency
  • Listing reference attached (portal enquiry on a specific ad)
  • Repeat contact / SLA breach (second touch without reply)
  • Source quality weight (referral > cold Instagram DM) — logistics only, documented
Banned: nationality, neighbourhood-as-person-quality, language ability as creditworthiness or “quality of person.” City is display-only.
User benefit: Agents and Chleo share one inspectable language for “why call now” — senior agreement measurable in the pilot.

Property search filters (assistive match)

Today: none. After a scored buyer lead, suggest listings with Idealista-class filters — matching ads, not scoring people.

  • Operation: buy / rent
  • Geo: district, concelho, freguesia / radius
  • Typology T0–T5+, rooms, useful m² range
  • Price min/max, condo fee max
  • Condition: new / used / needs work
  • Energy class
  • Amenities: parking, elevator, outdoor
  • Exclude already-rejected listing IDs
Filters are for assistive matching only — never a proxy for creditworthiness or “quality of person.”
User benefit: “Call this HOT lead with 3 relevant ads” — less blank-screen prep before the first touch.

Draft → human in the loop

Capstone MVP path stays one lane: score → explain → draft → approve/reject.

What the app does

  • Rules score + rationale (inspectable)
  • Optional LLM draft when credits remain
  • Agent edits freely
  • Approve = “ready for me to send”
  • Reject = park without that draft

What the app never does

  • No Gmail / Twilio / WhatsApp auto-send
  • No auto-booking of visits
  • COLD = park, never “reject housing”
  • No Idealista-style auto-qualifier bot
Sending stays on the licensed agent’s own channel. This is the product wedge vs portal AI that messages consumers for you.
User benefit: Speed of a draft without surrendering the licence, the tone, or the RGPD accountability of the first touch.

API cost control + central admin

Sell to individual agents; platform admin meters everything through a gateway.

Metering model

  • Rules-first scoring = zero LLM
  • LLM only for draft/explanation when credits remain
  • Per-tenant caps: scores, llm_tokens, listing_fetches
  • Soft stop at 80% · hard stop at 100%
  • Cache identical lead payloads · default mini model

Illustrative monthly quota use

55% — healthy

82% — soft stop / warn

100% — hard stop on billed calls

Central controls

  • One org API key + per-user login
  • Admin can disable user or whole tenant
  • Rotate keys · suspend / throttle
  • Usage dashboard: cost per lead, cost per approved draft
